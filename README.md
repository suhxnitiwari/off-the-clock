# Off the Clock

What I listen to, watch and read, off the clock.

**Live:** https://suhxnitiwari.github.io/off-the-clock/

- **Listen:** my live Spotify listening: a music universe of my top artists, On Repeat, my listening DNA, a listening clock and what I'm playing right now.
- **Watch:** the shows I rewatch on repeat, rom-coms, and the TED talks that stuck.
- **Read:** the books behind the business, and the ones I'll never shut up about.

## How it works

A static page (HTML, CSS, JavaScript) on GitHub Pages. The music section reads live data from my main site,
[suhanitiwari.com](https://suhanitiwari.com), which keeps my Spotify login private on its server and lets only
this site read its `/spotify` and `/music` answers.

This page used to live at suhanitiwari.com/home/favorites, and that address now sends you here.
